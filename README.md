## Como Compilar C++ e Executar Python

### 1. Como compilar e executar o código C++
Para compilar o arquivo C++ através do terminal, utilize o compilador g++:
bash
g++ nome_do_arquivo.cpp -o programa
./programa


### 2. Como executar o programa Python
Para rodar o script Python diretamente no terminal, utilize o comando correspondente à sua instalação:
bash
python nome_do_arquivo.py
# ou se o seu sistema exigir:
python3 nome_do_arquivo.py
